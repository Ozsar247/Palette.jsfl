# Palette.jsfl
Palette.jsfl is meant to act as a tool to easily use color palettes in Adobe Animate. 
Palette.jsfl also can be used as a method to share color palettes easily between computers, by simply sharing the asociated .palette file.

In addition, Palette.jsfl sets up the option to link certain colors in a palette to certain keybinds to accelerate workflows.

To use it, simply download the Palette JSFL Installer and run it in Adobe Animate. Everything is bundled in that file, and after following the instruction box, will install all required JSFLs and anything else.

To uninstall / fix a broken install, remove the Palettes folder from the Adobe Animate Configuration folder (can be found in %localappdata% on windows systems), remove the selected.palette file from the same folder, and remove all installed JSFLs from the Commands folder.
